# Support Vector Machines: Optimization and Machine Learning
Academic project developed as part of the MSc in Statistical Techniques at the Universidade de Santiago de Compostela.
## Overview
This project studies Support Vector Machines (SVMs) from both optimization and machine learning perspectives.

Starting from the classical linearly separable formulation, we derive and analyze soft-margin and kernelized SVMs through their associated dual optimization problems.

The methodology is subsequently applied to a real-world classification problem using data from the Spanish National Statistics Institute (INE), where the objective is to identify households at risk of poverty from socioeconomic indicators.
## Contents
* Introduction
* Linear SVMs
* C-SVMs (Soft-Margin SVMs)
* Dual Formulations
* Kernel Methods
* Polynomial and Gaussian Kernels
* Interpretation of Support Vectors
* Application to Real Data
* Conclusions
* References
## Tools
- R: Data preprocessing, statistical analysis, and preparation of the INE dataset for AMPL.
- AMPL: Formulation and solution of the optimization models associated with C-SVMs and Kernel SVMs.
- Python: Visualization of examples using NumPy and Matplotlib.
